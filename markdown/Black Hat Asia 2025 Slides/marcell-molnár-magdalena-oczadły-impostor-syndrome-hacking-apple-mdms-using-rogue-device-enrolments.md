- Check for legacy MDM endpoints, naming conventions may vary between MDM solutions

- Be mindful of any creds you push via MDM, they can be recovered in one way or another

- Use per machine random generated passwords when pushing admin accounts

- Put  SSO on self service separately, this is an option on most MDM solutions

- Do a security review of all items in self service, to avoid information leakage

- Do not put API credentials in shell scripts you push to the machines

- If you absolutely must, triple check credential privileges
