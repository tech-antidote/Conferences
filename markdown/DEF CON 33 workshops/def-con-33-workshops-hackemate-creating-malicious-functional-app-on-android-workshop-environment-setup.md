# **Welcome to DEF CON 33 Workshop — Environment Setup Guide**

Dear participants,

Welcome to the DEF CON 33 Workshop. We are pleased to have you join this intensive technical training experience, where we will explore advanced cybersecurity and ethical hacking practices.

To ensure you make the most of the sessions and follow the hands-on exercises in real time, it is essential that each participant sets up their environment beforehand. Below are the detailed requirements and recommended installation steps.

# **Environment Requirements**

# **1. Kali Linux 2025**

During the workshop, we will be using **Kali Linux 2025** as the main system for all practical exercises.

- **Reason** : Kali Linux provides pre-installed tools and configurations specifically designed for penetration testing and security assessments.

- **Optional** : If you are experienced and more comfortable with other distributions such as Parrot OS, you may use them. However, all in-class demonstrations will be conducted using Kali Linux 2025.

# _Installation Options_

- **Native installation** (recommended for advanced users): Install Kali Linux directly on your machine as the primary system or via dual boot.

- **Virtual machine installation** (recommended): Install Kali Linux using virtualization software. Recommended options include:

   - VirtualBox (https://www.virtualbox.org)

   - VMware Workstation Player

      - (https://www.vmware.com/products/workstation-player.html)

# **2. Android smartphone or emulator**

Some of the exercises will involve mobile applications and testing on Android devices.

_Recommended Options_

- **Physical Android smartphone**

   - If possible, use a secondary device rather than your primary phone, as we will be working with potentially insecure apps.

   - It is recommended to perform a factory reset before and after the workshop to protect personal data.

- **Android emulator**

   - BlueStacks (https://www.bluestacks.com): This will be the official emulator used during the class.

   - Other possible options: Android Studio Emulator or Genymotion (for experienced users).

# Additional Preparation

- Stable internet connection, preferably wired, to avoid disruptions.

- Administrative (root/sudo) access on the system where Kali Linux will be installed.

- Free disk space: at least 60 GB for Kali Linux and the emulator.

- RAM: at least 8 GB recommended.

# Pre-workshop Checklist

We strongly recommend verifying in advance that:

- Kali Linux boots correctly and has internet access.

- You can open the emulator or connect your Android device without issues.

- Your virtualization software is fully updated.
