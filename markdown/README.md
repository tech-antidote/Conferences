# Security conference talks — Markdown corpus

Machine-readable Markdown converted from the conference slide decks in this repository. Built for retrieval and LLM ingestion: one file per talk, YAML frontmatter for filtering, `## Slide N` headings as natural chunk boundaries.

Generated by [`tools/pdf2md.py`](../tools/pdf2md.py). See [`tools/README.md`](../tools/README.md) for the conversion design and its trade-offs.

## Files

- `INDEX.md` — every talk, grouped by conference, with speakers and links
- `manifest.jsonl` — one JSON record per talk; drive ingestion from this
- `<Conference Folder>/<slug>.md` — the converted talks

## Ingesting this corpus

Each file opens with YAML frontmatter:

```yaml
title: "..."
speakers: ["..."]
conference: "Black Hat"      # series, normalised across spellings
conference_full: "Black Hat USA 2026"
year: 2026
source_pdf: "..."            # provenance, exact source file
sha256: "..."                # detects upstream changes
pages: 58
ocr_pages: 55                 # how much of this doc is OCR-confidence
has_ocr: true
```

Two things worth doing at ingest time:

1. **Split on `## Slide N` headings, not character counts.** Slides are the natural semantic unit; fixed-size chunking cuts mid-thought.
2. **Copy the frontmatter into every chunk's metadata.** Frontmatter is stripped by most splitters, and without it a chunk loses the conference, year and speaker that make it filterable.

## Reading the output honestly

- Text inside a fenced block preceded by *"recovered by OCR"* came from Tesseract reading a slide image. It is approximate — identifiers, flags and hex values may be wrong. Treat it as a retrieval signal, and verify against `source_pdf` before quoting it as fact.
- A bare `## Slide N` with no body is a slide whose entire content was a photograph or diagram with no text. Nothing was lost in conversion; there was no text to extract. Recovering the meaning of those slides needs a vision model (see `tools/README.md`).
- Slide decks are supporting material for a spoken talk. They carry the technical substance but not the narration, so gaps in argument are expected.
