## How to resume a partial deck

Scratchpad work dirs are ephemeral. Re-extract, review only the resume range into
`corrections_B.jsonl`, then merge and apply:

```bash
python3 tools/verify_document.py --extract --doc "markdown/<deck>" --src . --work review-doc/
# review the resume-range pages -> review-doc/corrections_B.jsonl
cat review-doc/corrections_*.jsonl > review-doc/corrections.jsonl
python3 tools/verify_document.py --apply --doc "markdown/<deck>" --work review-doc/
python3 tools/refresh_manifest.py --out markdown
python3 tools/build_index.py --out markdown
python3 tools/vision_review_index.py --out markdown --record tools/vision_review.jsonl > markdown/VISION_VERIFIED.md
```
